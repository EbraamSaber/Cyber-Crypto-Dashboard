# 🛡️ Project Cybersecurity: Classical Encryption Algorithms

An interactive cryptographic dashboard built with **Python** and **Streamlit**. This project implements 10 different classical and modern encryption algorithms.

## 🚀 Project Overview
This application is designed for educational purposes to demonstrate various encryption techniques[cite: 6]. It supports:
*   Text encryption
*   `.txt` file uploads
*   **Image Pixel Encryption** using bitwise operations

### 🗝️ Implemented Algorithms
*   **RSA Encryption:** Asymmetric cipher
*   **Vigenère, Affine, Caesar, ROT13, Atbash:** Substitution ciphers
*   **Rail Fence, Columnar Transposition, Reverse:** Transposition ciphers
*   **XOR Cipher:** For binary data and images
